Introduction and security trends

Computer security protects the confidentiality, integrity and availability of information, often called the CIA triad. Network security applies the same goals to data in motion. Cryptography is the main tool, but it only works inside a wider design of policies, protocols and people.

Confidentiality: only authorised readersIntegrity: no unnoticed changeAvailability: service is there when needed

Trends worth knowing

Attacks have moved from curious individuals to organised crime and state groups. Ransomware, phishing and supply chain compromise now dominate. Remote work, cloud services and mobile devices have removed the old network edge, so encryption and authentication must follow the data.

OSI security architecture

ITU-T X.800 defines security with three linked ideas. An attack threatens security. A mechanism detects, prevents or recovers from it. A service is what the user finally receives, built from mechanisms.

Security attacks

Passive attacks only observe and are hard to detect, so we prevent them with encryption. Active attacks change or create traffic and are hard to prevent, so we detect and recover. Choose an attack to see the traffic path between Alice, Bob and the opponent Eve.

Models for network security

Model for network security

A secure channel needs a security transformation (encryption or a signature), secret information shared by both ends, and a trusted third party when keys must be distributed or disputes settled. Opponent Eve can read or tamper with the channel.

Symmetric cipher model

One shared key K encrypts and decrypts: C = E(K, P) and P = D(K, C). Security rests on keeping K secret, not the algorithm (Kerckhoffs’s principle). Attacks on a cipher are ciphertext-only, known-plaintext, chosen-plaintext and chosen-ciphertext.

Substitution techniques

Substitution replaces each plaintext unit with another. The Caesar cipher uses C = (P + k) mod 26. Vigenère uses a repeating key word, so the shift changes letter by letter. Hill encrypts letter blocks with a matrix (C = K·P mod 26). Playfair encrypts letter pairs from a 5×5 key square. Try Caesar and Vigenère below.

Block ciphers and design principles

A block cipher turns an n-bit block into an n-bit block under a key. Shannon’s two principles guide design: confusion hides the link between key and ciphertext, and diffusion spreads each plaintext bit over many ciphertext bits. A Feistel network splits the block into halves and repeats Li = Ri−1, Ri = Li−1 XOR F(Ri−1, Ki). Decryption runs the same steps with the subkeys reversed, so F need not be invertible.

The Data Encryption Standard

DES (1977) is a 16-round Feistel cipher with a 64-bit block and a 56-bit key. A block passes an initial permutation, 16 rounds, then the inverse permutation. In each round the function F expands the 32-bit half to 48 bits, XORs a 48-bit subkey, passes eight S-boxes (6 bits in, 4 bits out) and permutes the result. The S-boxes supply the nonlinearity.

The strength of DES

The key space of 256 fell to brute force: the EFF DES Cracker recovered a key in under three days in 1998. Differential and linear cryptanalysis need about 247 and 243 known or chosen plaintexts, so they are attacks in theory more than practice. DES shows a strong avalanche effect. Triple DES (EDE) lifts the effective key to 112 bits, and AES replaced both. Bars show key size in bits.
